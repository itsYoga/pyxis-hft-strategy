# 如何優化策略 PnL 為正數

## 問題分析

當前兩個策略的 PnL 都是負數，主要原因：

1. **PnL 計算錯誤** ✅ 已修復
   - 之前使用 `initial_capital` (30000) 而非實際初始 equity
   - 已修正為使用實際初始 equity

2. **策略參數需要優化**
   - 價差可能太緊，導致不利選擇
   - 風險厭惡係數可能不適合當前市場
   - 庫存管理可能過於激進

3. **市場條件**
   - 某些市場條件下，做市策略可能虧損
   - 需要更好的市場狀態檢測

---

## 優化方案

### 1. 調整策略參數

#### A. 擴大價差（減少不利選擇）

```yaml
# config/strategy_aggressive.yaml
strategy:
  parameters:
    k_base: 2.0  # 從 1.5 增加到 2.0，擴大價差
    gamma_base: 0.08  # 從 0.05 增加到 0.08，更保守
```

#### B. 調整 regime 參數

```yaml
regime:
  calm:
    spread_mult: 1.1  # 從 1.0 增加到 1.1
    alpha_mult: 0.9   # 從 1.0 減少到 0.9，降低對 alpha 的信任
  volatile:
    spread_mult: 1.5  # 從 1.1 增加到 1.5，波動時大幅擴大價差
    alpha_mult: 1.2   # 從 1.5 減少到 1.2
```

### 2. 實施更嚴格的庫存管理

```python
# src/strategies/aggressive.py
max_position = 8.0  # 從 10.0 減少到 8.0
order_qty = 0.8     # 從 1.0 減少到 0.8
```

### 3. 添加止損機制

```python
# 在策略中添加止損邏輯
max_loss_per_trade = 50.0  # 單筆交易最大虧損
if pnl < -max_loss_per_trade:
    # 停止交易或擴大價差
    k_base *= 1.5
```

### 4. 優化 MLOFI 權重

```python
# 降低對 MLOFI 的過度信任
mlofi_weight = 0.6  # 從 0.8 減少到 0.6
micro_weight = 0.3  # 從 0.2 增加到 0.3
```

### 5. 添加市場狀態過濾

```python
# 只在有利的市場條件下交易
if volatility > high_volatility_threshold:
    # 暫停交易或大幅擴大價差
    return
```

## 預期改進

### 短期（參數調整）

- **擴大價差**: 預期減少不利選擇，提高每筆交易利潤
- **降低風險厭惡**: 預期減少過度交易
- **更嚴格庫存管理**: 預期減少庫存風險

### 中期（策略優化）

- **市場狀態過濾**: 只在有利條件下交易
- **止損機制**: 限制最大虧損
- **動態價差調整**: 根據市場條件調整價差

### 長期（架構改進）

- **VPIN 毒性檢測**: 避免在有毒流動性中交易
- **DRL 架構**: 使用強化學習動態調整參數
- **隊列位置模擬**: 更準確的成交預測

## 監控指標

在優化過程中，監控以下指標：

1. **PnL**: 目標為正數
2. **Sharpe Ratio**: 目標 > 1.0
3. **最大回撤**: 目標 < 20%
4. **勝率**: 目標 > 50%
5. **平均每筆交易利潤**: 目標 > 0

---

## 注意事項

1. **不要過度優化**
   - 避免在單一數據集上過度擬合
   - 測試多個數據集

2. **平衡風險與收益**
   - 擴大價差會減少成交率
   - 需要在利潤和成交率之間平衡

3. **市場條件**
   - 某些市場條件下，做市策略可能不適合
   - 考慮添加市場狀態檢測
