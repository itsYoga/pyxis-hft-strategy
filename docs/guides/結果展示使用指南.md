# 結果展示使用指南

## 概述

`result_viewer.py` 提供了一個簡單易用的方式來展示回測結果，特別包含**按 tick 顯示波動率**的功能。

## 快速開始

### 基本使用

```python
from result_viewer import ResultViewer

# 建立結果展示器
viewer = ResultViewer(tick_size=0.1)

# 記錄每個時間步的數據
for i in range(n_steps):
    viewer.record_step(
        equity=equity[i],
        position=position[i],
        mid_price=price[i]
    )

# 打印摘要
viewer.print_summary()

# 繪製圖表（包含波動率）
viewer.plot_results(title="My Backtest Results")
```

### 在回測中使用

`backtest.py` 已經整合了結果展示工具，運行回測時會自動顯示：

```bash
python src/backtest.py data/binance_usdm/btcusdt_20240808.npz
```

結果會包含：
1. **權益曲線** - 顯示 PnL 變化
2. **回撤圖表** - 顯示最大回撤
3. **持倉變化** - 顯示持倉歷史
4. **波動率（按 tick）** - 顯示價格波動率，單位為 tick

## 功能說明

### 1. 按 Tick 顯示波動率

波動率計算使用滑動窗口標準差：

```python
volatility_ticks = viewer.calculate_volatility_by_tick(window=100)
```

- **單位**: tick（最小價格變動單位）
- **窗口**: 預設 100 個時間步
- **計算方式**: 價格變化的標準差（以 tick 為單位）

### 2. 結果摘要

`print_summary()` 會顯示：

- **資本**: 初始權益、最終權益、PnL
- **風險指標**: Sharpe Ratio、最大回撤
- **波動率**: 平均和最大波動率（tick）
- **持倉**: 平均、最大多頭、最大空頭
- **交易**: 總交易次數

### 3. 圖表展示

`plot_results()` 會生成 4 個子圖：

1. **權益曲線** - 顯示盈虧
2. **回撤圖表** - 顯示回撤百分比
3. **持倉變化** - 顯示持倉歷史
4. **波動率（tick）** - 顯示價格波動率

## API 參考

### ResultViewer 類別

#### 初始化

```python
viewer = ResultViewer(tick_size=0.1)
```

- `tick_size`: 最小價格變動單位

#### 記錄數據

```python
viewer.record_step(
    equity=float,        # 當前權益
    position=float,      # 當前持倉
    mid_price=float,     # 中間價
    volatility=float,    # 波動率（可選）
    timestamp=int        # 時間戳（可選）
)
```

#### 計算波動率

```python
volatility_ticks = viewer.calculate_volatility_by_tick(window=100)
```

- `window`: 滑動窗口大小
- 返回: numpy 陣列，波動率（tick 單位）

#### 打印摘要

```python
viewer.print_summary()
```

#### 繪製圖表

```python
viewer.plot_results(
    title="Results",      # 圖表標題
    save_path=None,      # 儲存路徑（可選）
    show=True            # 是否顯示
)
```

#### 儲存結果

```python
viewer.save_to_file("results.npz")
```

## 範例

### 完整範例

```python
import numpy as np
from result_viewer import ResultViewer

# 模擬數據
n_steps = 1000
equity = np.cumsum(np.random.randn(n_steps) * 10) + 30000
positions = np.cumsum(np.random.randn(n_steps) * 0.5)
prices = 50000 + np.cumsum(np.random.randn(n_steps) * 10)

# 建立展示器
viewer = ResultViewer(tick_size=0.1)

# 記錄數據
for i in range(n_steps):
    viewer.record_step(
        equity=equity[i],
        position=positions[i],
        mid_price=prices[i]
    )

# 顯示結果
viewer.print_summary()
viewer.plot_results(title="Example Results")
```

## 注意事項

1. **數據收集**: 目前策略在 JIT 編譯代碼中運行，無法實時收集數據。結果展示器會在策略執行後使用最終數據生成圖表。

2. **波動率計算**: 波動率是基於價格變化計算的，需要至少 2 個數據點。

3. **性能**: 對於大量數據點（>10,000），圖表生成可能需要一些時間。
