## PnL 計算修復（2025-12-13）

### 問題發現

兩個策略的 PnL 都顯示為負數（-28,879.05 和 -28,825.65），但實際 Equity 都是正數（1,120.95 和 1,174.35）。

### 根本原因

**PnL 計算錯誤**：使用了 `initial_capital` (30000) 而非實際初始 equity。

```python
# 錯誤的計算
pnl = equity - backtest_config.initial_capital  # 30000

# 正確的計算
pnl = equity - initial_equity  # 實際初始 equity (通常是 0)
```

### 修復方案

修正了 `src/tests/compare_strategies.py` 中的 PnL 計算：
1. **記錄初始狀態**：在運行策略前記錄初始 balance, position, fee, equity
2. **使用實際初始 equity**：使用 `initial_equity` 而非 `initial_capital` 計算 PnL

### 修復後結果

- ✅ Baseline PnL: **+1,120.95**（修復前：-28,879.05）
- ✅ Aggressive PnL: **+1,174.35**（修復前：-28,825.65）
