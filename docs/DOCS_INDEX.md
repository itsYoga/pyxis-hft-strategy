## 🚀 快速導航

### 新手入門
1. 閱讀 [GUIDE.md](GUIDE.md) 的「快速開始」部分
2. 運行 `python src/tests/compare_strategies.py` 測試策略
3. 查看 [REPORTS.md](REPORTS.md) 了解策略表現

### 策略優化
1. 閱讀 [GUIDE.md](GUIDE.md) 的「策略優化」部分
2. 參考 `guides/OPTIMIZE_PNL.md` 了解優化方法
3. 使用 `parameter_sweep.py` 進行參數掃描

### 實時交易
1. 閱讀 [GUIDE.md](GUIDE.md) 的「實時交易」部分
2. 參考 `guides/OKX_SIMULATED_TRADING.md` 設置環境
3. 啟動 `live_trading_optimized.py`
